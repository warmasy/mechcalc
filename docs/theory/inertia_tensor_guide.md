# 惯性张量入门教程：从直觉到姿态变换

> 面向初学者。目标：看懂惯性张量的每个数字、理解任意姿态惯量的求法、会用 mechcalc 计算。
> 配套库：`mechcalc`（pint 单位 + numpy 矩阵）。

---

## 1. 从直觉开始：转动惯量是什么

**一句话：转动惯量 = 物体"转起来有多难"的程度**，就像质量是"推起来有多难"。

| 生活例子 | 现象 | 道理 |
|---|---|---|
| 开门 | 推门把手省力，推门轴旁费力 | 离转轴越远越难转 |
| 转磨盘 | 又大又重，转起来费劲 | 质量大 + 离轴远 |
| 甩链球 | 甩得越远越难改变转动 | 距离的影响是**平方**级 |

最基础公式（一个点质量绕轴转）：

$$
J = m \cdot r^2
$$

不同形状只是"平均距离² × 形状系数"不同，形状系数是**固定的常数**，不用背：

| 形状 | 公式 | 系数含义 |
|---|---|---|
| 圆球 | $J = \frac{2}{5}mR^2$ | 球对称，任何轴一样 |
| 圆盘绕中心轴 | $J = \frac{1}{2}mR^2$ | 质量摊在盘面，离轴远 |
| 圆盘绕直径 | $J = \frac{1}{4}mR^2$ | 横着翻，省力一半 |
| 细杆绕中点 | $J = \frac{1}{12}mL^2$ | 质量沿杆分布 |

## 2. 惯性张量：为什么需要 3×3 矩阵

### 2.1 由来（从角动量定律自然长出）

一切从**角动量**出发。质量为 m 的物体绕 ω 旋转，角动量：

$$
\mathbf{L} = \mathbf{r} \times \mathbf{p} = m\,\mathbf{r} \times (\boldsymbol{\omega} \times \mathbf{r})
$$

**一维退化**（绕已知单轴）：$L = m r^2 \omega = J\omega$ —— 这就是转动惯量最早的形态。

**三维展开**：$\mathbf{r} \times (\boldsymbol{\omega} \times \mathbf{r}) = \boldsymbol{\omega}(\mathbf{r}\cdot\mathbf{r}) - \mathbf{r}(\mathbf{r}\cdot\boldsymbol{\omega})$，逐分量展开后：

$$
\begin{bmatrix} L_x \\ L_y \\ L_z \end{bmatrix}
=
\underbrace{
\begin{bmatrix}
m(y^2+z^2) & -mxy & -mxz \\
-mxy & m(x^2+z^2) & -myz \\
-mxz & -myz & m(x^2+y^2)
\end{bmatrix}
}_{\text{惯量张量 } \mathbf{I}}
\begin{bmatrix} \omega_x \\ \omega_y \\ \omega_z \end{bmatrix}
$$

即 $\mathbf{L} = \mathbf{I} \cdot \boldsymbol{\omega}$。**这个矩阵不是人为规定的，是从 $\mathbf{L} = \mathbf{r}\times(m\mathbf{v})$ 数学展开的必然结果。**

### 2.2 原理：为什么必然是矩阵

转动惯量描述的是 **"角速度 ω（输入3个数）→ 角动量 L（输出3个数）"的线性关系**。三维空间的线性关系天然就是一个 3×3 矩阵——因为偏心物体的 ωx 会同时影响 Lx、Ly、Lz 三个分量（每个输出分量需要 3 个系数）。

### 2.3 标量 vs 张量

| | 标量 J | 张量 I |
|---|---|---|
| 什么时候够用 | 对称物体绕**主轴**转（ω ∥ L） | 一般情况（任意轴、偏心、姿态变化） |
| 能算什么 | 那一根轴的惯量 | 任意轴、任意姿态、组合体、动力学 |
| 缺点 | 一转姿态就失效 | 完整，永远够用 |

> **标量 J 是张量的特例**：ω 沿主轴时，$\mathbf{I}\cdot\boldsymbol{\omega} = J\boldsymbol{\omega}$，矩阵退化为一个数。

## 3. 惯性张量中每个数值：学名、表示方法、物理含义

### 3.1 完整标注矩阵

```
             绕 x 轴                绕 y 轴                绕 z 轴
        ┌────────────────────┬────────────────────┬────────────────────┐
绕 x 轴 │ Ixx                │ Ixy                │ Ixz                │
        │ 转动惯量(绕x轴)     │ 惯性积(x-y)        │ 惯性积(x-z)        │
        ├────────────────────┼────────────────────┼────────────────────┤
绕 y 轴 │ Iyx                │ Iyy                │ Iyz                │
        │ 惯性积(y-x)        │ 转动惯量(绕y轴)     │ 惯性积(y-z)        │
        ├────────────────────┼────────────────────┼────────────────────┤
绕 z 轴 │ Izx                │ Izy                │ Izz                │
        │ 惯性积(z-x)        │ 惯性积(z-y)        │ 转动惯量(绕z轴)     │
        └────────────────────┴────────────────────┴────────────────────┘
```

### 3.2 术语表

| 位置 | 符号 | 学名 | 英文 | 物理含义 |
|---|---|---|---|---|
| 对角线 | Ixx / Iyy / Izz | **转动惯量**（轴惯量） | moment of inertia | 绕这根轴转动的难度 |
| 非对角线 | Ixy、Ixz、Iyz | **惯性积** | product of inertia | 质量"歪"的程度：绕 x 转会连带产生 y/z 方向的角动量 |
| 整个矩阵 | **I** | **惯性张量** | inertia tensor | 所有方向转动难度的完整地图 |
| eig 特征值 | J₁、J₂、J₃ | **主惯量** | principal moments of inertia | 沿主轴的转动惯量 |
| eig 特征向量 | — | **主轴** | principal axes | 最省力/最费力的方向 |

### 3.3 关键性质

- **对称性**：$I_{xy} = I_{yx}$、$I_{xz} = I_{zx}$、$I_{yz} = I_{zy}$ —— 9 个位置只有 **6 个独立数字**（3 个转动惯量 + 3 个惯性积）
- **单位**：kg·m²
- **对称物体的非对角线全为 0**（圆球、圆柱、圆盘……对称形状）
- **非对角线 ≠ 0** = 质量偏心 = 转动会抖（动平衡要消除它）

### 3.4 必要条件：质心 + 坐标系

惯性张量必须**相对一个点（通常质心）和一套 XYZ 轴**定义：

- 原点在质心（要绕其他点转，用平行移轴定理）
- XYZ 轴方向要约定（**mechcalc 约定：右手系、z 轴向上、对称轴为 z**）
- 坐标系不同 → 同一个物体的张量数字不同

## 4. 常见形状的惯性张量（球、圆柱、圆杆）

以下均约定：**对称轴为 z 轴，原点在质心**。

### 4.1 圆球（质量 m，半径 R）

$$
\mathbf{I} =
\begin{bmatrix}
\frac{2}{5}mR^2 & 0 & 0 \\
0 & \frac{2}{5}mR^2 & 0 \\
0 & 0 & \frac{2}{5}mR^2
\end{bmatrix}
$$

三个主轴惯量相等——球绕任何轴转都一样。

**例**：m = 10 kg，R = 100 mm → $J = \frac{2}{5}\times10\times0.1^2 = 0.04$ kg·m²

$$
\mathbf{I} =
\begin{bmatrix}
0.04 & 0 & 0 \\
0 & 0.04 & 0 \\
0 & 0 & 0.04
\end{bmatrix}
\text{ kg·m}^2
$$

### 4.2 圆柱（质量 m，半径 R，长 L，对称轴为 z）

$$
\mathbf{I} =
\begin{bmatrix}
\frac{m(3R^2+L^2)}{12} & 0 & 0 \\
0 & \frac{m(3R^2+L^2)}{12} & 0 \\
0 & 0 & \frac{mR^2}{2}
\end{bmatrix}
$$

绕 z（对称轴）最省力；绕 x/y 横着转费力（多了 L² 项）。

**例**：m = 10 kg，D = 100 mm（R = 0.05 m），L = 200 mm

- $I_{zz} = 10\times0.05^2/2 = 0.0125$
- $I_{xx} = I_{yy} = 10\times(3\times0.05^2 + 0.2^2)/12 = 0.0396$

$$
\mathbf{I} =
\begin{bmatrix}
0.0396 & 0 & 0 \\
0 & 0.0396 & 0 \\
0 & 0 & 0.0125
\end{bmatrix}
\text{ kg·m}^2
$$

### 4.3 细圆杆（质量 m，长 L，沿 z 轴）

$$
\mathbf{I} =
\begin{bmatrix}
\frac{mL^2}{12} & 0 & 0 \\
0 & \frac{mL^2}{12} & 0 \\
0 & 0 & 0
\end{bmatrix}
$$

绕自身轴（z）惯量为 0（理想细杆的半径忽略不计）；横着转 $\frac{mL^2}{12}$。

**例**：m = 2 kg，L = 300 mm → $I_{xx} = I_{yy} = 2\times0.3^2/12 = 0.015$

$$
\mathbf{I} =
\begin{bmatrix}
0.015 & 0 & 0 \\
0 & 0.015 & 0 \\
0 & 0 & 0
\end{bmatrix}
\text{ kg·m}^2
$$

## 5. 惯性张量不都是对角矩阵：非对角例子与主轴对角化

第 4 章三个形状都是对角矩阵——因为**坐标轴恰好对齐了主轴**。但一般情况（偏心、物体转歪）**不是对角的**。这一章讲透：什么时候非对角、以及如何把任何张量变回对角。

### 5.1 先理解：对称轴与坐标轴的"对齐"

**两个词先分开：**

- **对称轴** = 物体身上那根"最特殊"的轴（圆柱绕它转最省力，质量绕它对称分布）。可乐罐的对称轴 = **从盖到底**那根轴（绕它转像拧瓶盖，最省力）。
- **坐标轴** = 你画的坐标系（x、y、z 三条方向线），例如规定 x = 右、y = 前、z = 上。

**"对齐" = 物体的对称轴方向和某条坐标轴方向重合（同方向）。**

用可乐罐演示：

```
坐标系:  z ↑        z ↑            z ↑
         |           |              |
         +──→ x      +──→ x         +──→ x
      可乐罐竖着    可乐罐横着     可乐罐斜 30°

      对称轴 = z    对称轴 = x    对称轴 = 指向上斜 30°
      (从盖到底)   (盖朝右)      (和 x、y、z 都不重合)
      ═══ 对齐 ═══  ═══ 对齐 ═══   ═══ 不对齐 ═══
```

- **竖着**：盖朝上，对称轴恰好和 z 轴重合 → **对齐**
- **横着**：盖朝右，对称轴恰好和 x 轴重合 → **对齐**（换了一条轴对齐而已）
- **斜 30°**：盖指向上斜 30° 的方向，和 x、y、z **哪条都不重合** → **不对齐**

**对齐 ↔ 对角 的关系：**

- **对齐 → 对角**：从坐标轴看过去，质量分布是"端正"的 → 惯性积 = 0 → 张量对角
- **不对齐 → 非对角**：从坐标轴看过去，质量是"斜着"的 → 惯性积 ≠ 0 → 张量非对角

为什么？因为惯性积描述的是"质量相对坐标轴是否**斜着堆**"：对称轴对齐 z 轴时，质量绕 z 完全对称，相对 x、y 都不偏 → 惯性积 = 0；对称轴斜 30° 时，从 x、z 方向看过去质量"一边多一边少" → 惯性积 ≠ 0。

用代码把可乐罐（圆柱）绕 y 转一圈验证：

| 角度 | 对称轴方向 | 张量状态 |
|---|---|---|
| 0° | 对齐 z 轴 | ✅ 对角 |
| 30° | 歪着，哪条轴都不重合 | ⚠️ 非对角（Ixz = −0.0117） |
| 45° | 歪着 | ⚠️ 非对角（Ixz = −0.0135） |
| 60° | 歪着 | ⚠️ 非对角（Ixz = −0.0117） |
| 90° | 对齐 x 轴 | ✅ 对角 |

> **一句话**：张量是"从你画的坐标轴看物体"的描述——**物体摆得正（对齐），描述就干净（对角）；摆得歪（不对齐），描述就带"交叉项"（非对角）**。

### 5.2 非对角矩阵的三个例子

**例 A：转盘 + 斜放的小块（偏心，工程最常见）**

场景：m=10 kg 转盘（D=200 mm）上，在 (x, y) = (0.1, 0.05) m 处焊了一个 1 kg 的小块。

$$
\mathbf{I} =
\begin{bmatrix}
0.0275 & -0.005 & 0 \\
-0.005 & 0.035 & 0 \\
0 & 0 & 0.0625
\end{bmatrix}
\text{ kg·m}^2
$$

- **Ixy = −0.005 ≠ 0**：小块同时偏离 x 和 y 方向（质量"斜着堆"）
- 物理后果：绕 x 转时会连带产生 y 方向的角动量 → **转起来会抖**
- 这就是为什么洗衣机衣服要放均匀、轮胎要做动平衡

**例 B：圆柱绕 y 转 30°（姿态变换产生非对角）**

场景：圆柱（m=10, D=100, L=200）绕 y 轴倒 30°（之前第 7 章的例子）。

$$
\mathbf{I}' =
\begin{bmatrix}
0.0328 & 0 & -0.0117 \\
0 & 0.0396 & 0 \\
-0.0117 & 0 & 0.0193
\end{bmatrix}
\text{ kg·m}^2
$$

- **Ixz = −0.0117 ≠ 0**：圆柱"歪"了，对称轴不再对齐坐标轴
- 只有 0°、90° 这种"对齐"角度才是对角；**任意角度（30°、45°…）都非对角**

**例 C：45° 斜杆（两个质点组成，最干净的例子）**

场景：两个 1 kg 质点分别在 (0.1, 0.1, 0) 和 (−0.1, −0.1, 0) m（一根沿 45° 方向放置的杆）。

$$
\mathbf{I} =
\begin{bmatrix}
0.02 & -0.02 & 0 \\
-0.02 & 0.02 & 0 \\
0 & 0 & 0.04
\end{bmatrix}
\text{ kg·m}^2
$$

- **Ixy = −0.02 ≠ 0**：杆斜着放
- 物理直觉：绕杆自身方向转**很轻松**（惯量小），绕垂直方向转费力——张量里"0 的位置"其实就藏在杆的方向上，只是坐标系没对齐

### 5.3 核心定理：任何惯性张量都能对角化（主轴）

**每个物体（无论多不规则）都有 3 个互相垂直的"主轴"**：

- 绕主轴转时，角速度 ω 和角动量 L **方向一致**（无交叉效应）
- **把坐标轴转到主轴上，非对角线全部消失，只留"主惯量"在对角线上**

**找主轴 = 对张量做特征值分解**（`eig`）：

$$
\mathbf{I} = \mathbf{V}\,\text{diag}(J_1, J_2, J_3)\,\mathbf{V}^T
$$

- 特征值 $J_1, J_2, J_3$ = **主惯量**
- 特征向量（V 的列）= **主轴方向**
- 对角化公式：$\mathbf{I}_{\text{principal}} = \mathbf{V}^T \mathbf{I} \mathbf{V}$

### 5.4 例 C 对角化（斜杆，数字全验证）

原始（非对角，Ixy = −0.02）→ 用 `eig` 找主轴：

- 主惯量 = [0, 0.04, 0.04]
- 主轴 = (0.707, −0.707, 0)（**沿杆方向**，惯量 = 0）、(0.707, 0.707, 0)（垂直杆，0.04）、z 轴（0.04）

把坐标系转到主轴上（$\mathbf{V}^T\mathbf{I}\mathbf{V}$）：

$$
\mathbf{I}_{\text{principal}} =
\begin{bmatrix}
0.04 & 0 & 0 \\
0 & 0 & 0 \\
0 & 0 & 0.04
\end{bmatrix}
\text{ kg·m}^2
$$

**完美对角**——绕杆方向惯量 = 0（第一个主轴），绕垂直方向 = 0.04。

### 5.5 例 A 对角化（转盘 + 小块）

主惯量 = [0.025, 0.0375, 0.0625]，主轴在 x-y 平面内转过一个角度（对准小块的偏心方向）：

$$
\mathbf{I}_{\text{principal}} =
\begin{bmatrix}
0.025 & 0 & 0 \\
0 & 0.0375 & 0 \\
0 & 0 & 0.0625
\end{bmatrix}
\text{ kg·m}^2
$$

### 5.6 主轴对角化的用途

1. **找"最省力的轴"**：最小主惯量对应的主轴方向（选电机、选转轴方向）
2. **判断是否要动平衡**：非对角越大，偏心越严重
3. **简化计算**：主轴系下张量是对角的，$\mathbf{I}\boldsymbol{\omega} = (J_1\omega_1, J_2\omega_2, J_3\omega_3)$ 一行搞定

**代码**：

```python
from mechcalc import Q_, eig

I = Q_(np.array([[0.02, -0.02, 0], [-0.02, 0.02, 0], [0, 0, 0.04]]), 'kg*m**2')
J_principal, axes = eig(I)          # 主惯量 + 主轴（列）
I_diag = axes.T @ I.magnitude @ axes  # 对角化验证
```

## 6. 任意姿态惯量的求法及公式

"姿态变了"有**两种情况**，算法不同：

### 情况 A：物体不动，只换转轴方向

用**等效惯量公式**（矩阵不用动）：

$$
J = \mathbf{n}^T \mathbf{I} \mathbf{n}
$$

- n = 新转轴方向的单位向量
- 支持批量：n 为 (N,3) 矩阵时一次算 N 根轴

**代码**：`inertia_about_axis(I, n)`

### 情况 B：物体旋转了（姿态变化）

用**张量变换公式**：

$$
\mathbf{I}' = \mathbf{R}\,\mathbf{I}\,\mathbf{R}^T
$$

- R = 姿态的旋转矩阵（3×3）
- I′ = 物体按 R 摆放后，在**原坐标系**里的新惯性张量

**代码**：`I.T` 后 `R @ I @ R.T`（或封装函数 `rotate_tensor`）

### 完整两步链（先变姿态，再问任意轴）

$$
J = \mathbf{n}^T (\mathbf{R}\,\mathbf{I}\,\mathbf{R}^T)\, \mathbf{n}
$$

## 7. 姿态变化的表示方法

### 6.1 旋转矩阵 R（姿态 = 3×3 矩阵）

绕单轴的旋转矩阵（右手系）：

$$
\mathbf{R}_x(\alpha) =
\begin{bmatrix}
1 & 0 & 0 \\
0 & \cos\alpha & -\sin\alpha \\
0 & \sin\alpha & \cos\alpha
\end{bmatrix},\quad
\mathbf{R}_y(\theta) =
\begin{bmatrix}
\cos\theta & 0 & \sin\theta \\
0 & 1 & 0 \\
-\sin\theta & 0 & \cos\theta
\end{bmatrix},\quad
\mathbf{R}_z(\psi) =
\begin{bmatrix}
\cos\psi & -\sin\psi & 0 \\
\sin\psi & \cos\psi & 0 \\
0 & 0 & 1
\end{bmatrix}
$$

**代码**：`rot_x(angle)` / `rot_y(angle)` / `rot_z(angle)`（角度支持 deg 的 Quantity）

### 6.2 R 的转置 Rᵀ = 反向旋转

转置规则：**行变列、列变行**（沿对角线翻转），数字不动只换位置。旋转矩阵的特殊性质：

$$
\mathbf{R}^T = \mathbf{R}^{-1}
$$

即 Rᵀ 代表"反向转回"。在 $\mathbf{I}' = \mathbf{R}\mathbf{I}\mathbf{R}^T$ 里，R 负责正转、Rᵀ 负责回转，完成坐标翻译。

### 6.3 任意姿态 = 基本旋转连乘（欧拉角）

$$
\mathbf{R} = \mathbf{R}_z(\psi)\cdot\mathbf{R}_y(\theta)\cdot\mathbf{R}_x(\varphi)
$$

**代码**：`R = rot_y(Q_(45,'deg')) @ rot_z(Q_(30,'deg'))`

### 6.4 为什么 I′ 要"乘两次"（R 和 Rᵀ）

因为惯性张量是**二阶量**（涉及两个方向），需要两个旋转矩阵翻译；向量（力、速度）只要一个 R（F′ = R·F）。

## 8. 完整例子：三种形状的姿态变换

### 例 1：圆球（m=10, R=100mm）——任意姿态不变

圆球张量是常数 × 单位矩阵：$\mathbf{I} = 0.04\,\mathbf{E}$

$$
\mathbf{I}' = \mathbf{R}\,(0.04\mathbf{E})\,\mathbf{R}^T = 0.04\,(\mathbf{R}\mathbf{R}^T) = 0.04\,\mathbf{E} = \mathbf{I}
$$

**绕 y 转 30°、45°、90°，张量永远是**：

$$
\mathbf{I}' =
\begin{bmatrix}
0.04 & 0 & 0 \\
0 & 0.04 & 0 \\
0 & 0 & 0.04
\end{bmatrix}
$$

→ 球怎么摆都一样，这就是"球对称"。

### 例 2：圆柱（m=10, D=100, L=200mm）——绕 y 转 30°

原始（竖直，对称轴 = z）：

$$
\mathbf{I} =
\begin{bmatrix}
0.0396 & 0 & 0 \\
0 & 0.0396 & 0 \\
0 & 0 & 0.0125
\end{bmatrix}
$$

姿态矩阵（绕 y 转 30°，cos30°=0.866，sin30°=0.5）：

$$
\mathbf{R} =
\begin{bmatrix}
0.866 & 0 & 0.5 \\
0 & 1 & 0 \\
-0.5 & 0 & 0.866
\end{bmatrix}
$$

变换后 $\mathbf{I}' = \mathbf{R}\mathbf{I}\mathbf{R}^T$：

$$
\mathbf{I}' =
\begin{bmatrix}
0.0328 & 0 & -0.0117 \\
0 & 0.0396 & 0 \\
-0.0117 & 0 & 0.0193
\end{bmatrix}
\text{ kg·m}^2
$$

**观察**：圆柱"歪"了 30° → **非对角线出现**（Ixz = −0.0117），绕 x 转与 z 方向耦合。各轴惯量：绕 x = 0.0328、绕 y = 0.0396、绕 z = 0.0193。

**同例验证**：绕 y 转 90°（圆柱躺平）→ Ixx ↔ Izz 互换，非对角线归零：

$$
\mathbf{I}' =
\begin{bmatrix}
0.0125 & 0 & 0 \\
0 & 0.0396 & 0 \\
0 & 0 & 0.0396
\end{bmatrix}
$$

### 例 3：细圆杆（m=2, L=300mm）——从沿 z 变到沿 x

原始（沿 z）：

$$
\mathbf{I} =
\begin{bmatrix}
0.015 & 0 & 0 \\
0 & 0.015 & 0 \\
0 & 0 & 0
\end{bmatrix}
$$

姿态矩阵（绕 y 转 90°，把杆放平到 x 方向）：

$$
\mathbf{R} = \mathbf{R}_y(90°) =
\begin{bmatrix}
0 & 0 & 1 \\
0 & 1 & 0 \\
-1 & 0 & 0
\end{bmatrix}
$$

变换后 $\mathbf{I}' = \mathbf{R}\mathbf{I}\mathbf{R}^T$：

$$
\mathbf{I}' =
\begin{bmatrix}
0 & 0 & 0 \\
0 & 0.015 & 0 \\
0 & 0 & 0.015
\end{bmatrix}
\text{ kg·m}^2
$$

**观察**：杆现在沿 x → 绕 x（自身轴）为 0，绕 y/z（横着转）= 0.015——"0.015 和 0"的位置跟随杆的方向移动了。

### 例 4：任意斜轴的惯量（物体不动，换转轴）

圆柱（原始竖直张量）绕与 z 轴成 45° 的斜轴 $\mathbf{n} = (0, \sin45°, \cos45°)$：

$$
J = \mathbf{n}^T\mathbf{I}\,\mathbf{n} = 0.0396 \times 0 + 0.0396 \times 0.5 + 0.0125 \times 0.5 = 0.0260 \text{ kg·m}^2
$$

**代码**：`inertia_about_axis(I, [0, np.sin(np.pi/4), np.cos(np.pi/4)])`

## 9. FAQ：姿态变换后还叫惯性张量吗？

**答：是的，仍然叫惯性张量。** I′ 和 I 是**同一个惯性张量**在不同坐标系下的表示。

类比：

- **向量**：同一个位移向量，在坐标系 A 里是 (1,0,0)，在坐标系 B 里是 (0,1,0)——它还是同一个向量，只是分量不同。
- **惯性张量**同理：它是"**贴在物体身上的物理量**"。I（质心系/物体系）和 I′（旋转后的世界系）描述同一个物体的同一套转动属性，只是"从哪个角度看"不同。物体本身没变，变的是观察角度。

严格地说，惯性张量是**二阶张量**（不是普通矩阵）——它的定义性特征就是满足坐标变换律：

$$
\mathbf{I}' = \mathbf{R}\,\mathbf{I}\,\mathbf{R}^T
$$

**满足这个变换律的量才叫"张量"**，普通矩阵不需要满足。所以"姿态变换后"它不但还叫惯性张量，而且**正因为遵守这条变换律，它才是惯性张量**。

一句话：**I 和 I′ 是同一个惯性张量的两张"证件照"——一个正面照、一个侧脸照，人还是那个人。**

## 10. 用 mechcalc 验证全部例子（可运行代码）

```python
import numpy as np
from mechcalc import (
    solid_cylinder_tensor, inertia_about_axis,
    rot_x, rot_y, rot_z, Q_,
)

# ---- 例1: 圆球（三个主轴惯量相等）----
# 项目里 sphere() 返回标量 dict: J_x = J_y = J_z = 0.04
# 张量 = diag(0.04, 0.04, 0.04), 任意姿态不变

# ---- 例2: 圆柱绕 y 转 30° ----
I = solid_cylinder_tensor(10, 100, 200)        # diag(0.0396, 0.0396, 0.0125)
R = rot_y(Q_(30, 'deg'))
I_rot = R @ I.magnitude @ R.T                  # 出现非对角 -0.0117
print(np.round(I_rot, 4))

# ---- 例3: 细杆从沿 z 变到沿 x ----
I_rod = Q_(np.diag([0.015, 0.015, 0.0]), 'kg*m**2')
R2 = rot_y(Q_(90, 'deg'))
I_rod_rot = R2 @ I_rod.magnitude @ R2.T        # 0 移动到 xx 位
print(np.round(I_rod_rot, 4))

# ---- 例4: 任意斜轴 ----
n = [0, np.sin(np.pi/4), np.cos(np.pi/4)]
J = inertia_about_axis(I, n)                   # 0.0260 kg·m²
print(J)
```

## 11. 一页速查表

| 概念 | 公式/要点 |
|---|---|
| 转动惯量（标量） | $J = m r^2$，形状系数固定 |
| 惯性张量（矩阵） | $\mathbf{L} = \mathbf{I}\boldsymbol{\omega}$ 展开的必然结果 |
| 对角线 | Ixx/Iyy/Izz 转动惯量 |
| 非对角线 | Ixy/Ixz/Iyz 惯性积（偏心程度） |
| 对角矩阵 | 坐标轴对齐主轴时才是（对称物体天然对角） |
| 主轴与对角化 | $\mathbf{I}_{\text{principal}} = \mathbf{V}^T\mathbf{I}\mathbf{V}$（V 的列 = 主轴，特征值 = 主惯量） |
| 对称性 | $I_{xy}=I_{yx}$ 等，6 个独立数字 |
| 任意轴 | $J = \mathbf{n}^T\mathbf{I}\mathbf{n}$ |
| 姿态变换 | $\mathbf{I}' = \mathbf{R}\mathbf{I}\mathbf{R}^T$ |
| 姿态表示 | $\mathbf{R} = \mathbf{R}_z\mathbf{R}_y\mathbf{R}_x$（欧拉角） |
| Rᵀ | R 的转置 = 反向旋转 |
| 变换后还是张量吗 | **是**——满足 $I'=RIR^T$ 正是"张量"的定义 |
